# nekuroddo v0.1.0

A primeira versão marcada do nekuroddo, o orquestrador TUI das suas sessões do
[Claude Code](https://claude.com/claude-code). Até aqui o projeto se chamava `neko`; o gato `ᓚᘏᗢ` continua
no canto.

## Destaques

**Grupos de agents ✉.** Sessões que fazem trabalho parecido agora se avisam. Selecione com `space`, rode
`:group deploy-rc` e cada membro fica sabendo dos pares pelo novo hook `nk hook-context`. Quando uma acha um
bug que vale para as outras, ela avisa com o `SendMessage` nativo do Claude Code, e o nekuroddo mostra `✉→` em
quem mandou, `✉←` em quem recebeu e o miado com quem falou com quem. `:notify #tag <mensagem>` manda uma nota
sua para o grupo inteiro. Guia: [docs/grupos.md](https://github.com/aqilputi/nekuroddo/blob/main/docs/grupos.md).

**Novo nome, comando curto.** O projeto agora é `nekuroddo`, e o comando do dia a dia é `nk`:

```sh
go install github.com/aqilputi/nekuroddo/cmd/nekuroddo@latest
ln -sf "$(go env GOPATH)/bin/nekuroddo" ~/.local/bin/nk
# ou, do clone: make install
```

**Projeto pronto para contribuições.** `Makefile` (`build`, `install`, `test`, `cover`, `lint`, `ci`),
`golangci-lint`, CI no GitHub Actions, logo, `CONTRIBUTING.md`, `SECURITY.md` e templates de issue e PR.

Também nesta versão: renomear sessão ou seção (`n`), mover sessão de contexto (`m`), layout 1/3 lista · 2/3
painel, descrições das issues do Jira no detalhe e no prompt do agent, e a correção da criação de issue do
Jira com `defaultMode: auto`. Lista completa no
[CHANGELOG](https://github.com/aqilputi/nekuroddo/blob/main/CHANGELOG.md).

## Atualizando a partir do `neko`

1. **Instale de novo.** Use o `go install` acima ou `make install` num clone atualizado. O binário antigo
   (`~/.local/bin/neko`) pode ser apagado.
2. **Dados:** nada a fazer. Na primeira execução, da TUI ou de qualquer hook, `~/.config/neko`,
   `~/.local/state/neko` e `~/.cache/neko` são renomeados para `…/nekuroddo`. Nada é sobrescrito: se o
   diretório novo já existir, o antigo fica onde está.
3. **Hooks:** em `~/.claude/settings.json`, troque `neko hook` por `nk hook` em todas as entradas.
4. **Grupos (opcional):** acrescente o hook síncrono `nk hook-context` em `SessionStart`,
   `UserPromptSubmit` e `PostToolUse`, com `"timeout": 5` e **sem** `async`. O JSON completo está em
   [docs/hooks.md](https://github.com/aqilputi/nekuroddo/blob/main/docs/hooks.md).
5. **Clone antigo:** `git remote set-url origin https://github.com/aqilputi/nekuroddo`.

## Mudanças de comportamento

- `space` agora **seleciona** sessões (para o `:group`). Numa linha de contexto ele continua dobrando a seção,
  e `h`/`l` continuam abrindo e fechando nós. `esc` limpa a seleção.

## Requisitos

- Go 1.27.2+
- Claude Code 2.1+ com `claude agents`, `claude --bg` e `claude attach`
- Linux (macOS não testado)

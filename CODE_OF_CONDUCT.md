# Código de Conduta

Este projeto adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: seja respeitoso, assuma boa-fé, critique ideias e não pessoas, e não tolere assédio. Isso vale para
issues, pull requests, discussões e qualquer espaço do projeto.

Para relatar um comportamento inaceitável, use o
[reporte privado do GitHub](https://github.com/aqilputi/nekuroddo/security/advisories/new) ou fale diretamente
com o mantenedor pelo perfil [@aqilputi](https://github.com/aqilputi). Os relatos são tratados com sigilo.
